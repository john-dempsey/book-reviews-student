Lesson 2: Seeding & Browsing the Catalogue

Real factories and seeders producing a believable demo catalogue, then read-only routes for browsing it - and the tests that prove both work.

  • Writing factories

    One factory per model - AuthorFactory, BookFactory, ReviewFactory - and the HasFactory trait that turns each model into something that can conjure realistic-looking rows on demand.

  • Seeders and demo data

    Turning last topic's ad hoc factory calls into a repeatable command that builds a whole believable catalogue in one go - one seeder per model, wired together in an order that matters, and the ReviewFactory default that has to be worked around to make it happen.

  • Reading the catalogue: index and show

    BookController and AuthorController's read-only index/show actions, wired to real routes with route model binding - then the Blade layout, partials, and loops that turn seeded rows into an actual catalogue you can click through.

  • Testing the read-only routes

    Proving the factories and seeder still behave as documented, then this project's first feature tests - real HTTP requests against books.index/show and authors.index/show, checking the response the way a browser actually would.
