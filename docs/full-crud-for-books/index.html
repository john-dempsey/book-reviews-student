Lesson 3: Full CRUD for Books

Add create, edit, and delete to the read-only catalogue from Lesson 2 - validation and form repopulation, a shared form partial, cover image upload, and the tests that prove the whole flow works.

  • Create and store

    BookController@create and @store - the first form this course writes by hand, @csrf, and route model binding run in reverse to redirect straight to the book that was just created.

  • Validation and form repopulation

    $request->validate() replaces the hand-written validator class and manual PRG flow from the PHP module - rule strings, automatic redirect-back-with-errors on failure, and old()/@error in Blade.

  • Edit, update, and image upload

    edit/update mirror create/store almost exactly - the interesting new ground is a form shared between the two pages, and a cover image saved to Laravel's public disk.

  • Delete

    BookController@destroy, a spoofed DELETE request behind a confirm() dialog, and closing the orphaned-file gap the last topic left open on purpose.

  • Testing the full CRUD flow

    Feature tests for store, update, and destroy - a validation failure that actually repopulates the form, a cover image that actually leaves storage, and one test that runs create, edit, and delete back to back.
