Lesson 5: Search

A search box on the catalogue - title first, then author and year - built on query scopes, a natural extension of the relationships from Lessons 1-2. Kept deliberately brief: a flavour of what's involved, not a full search feature.

  • Basic search by title

    A search box on books.index, backed by a query scope on Book - the first reusable, chainable piece of query logic this app has written on a model itself, plus withQueryString() to keep a search term alive across pagination links.

  • Author, year, and the limits of LIKE

    Widening scopeSearch() to also match an author's name and a book's year - orWhereHas(), a grouped where() closure to keep the OR conditions from leaking into the rest of the query, and a short look at what LIKE can't do.

  • Testing search

    Feature tests proving the search box actually narrows the catalogue by title, author, and year, plus unit tests locking scopeSearch()'s three matching branches - and the non-matching and blank-term cases - down directly on the model.
